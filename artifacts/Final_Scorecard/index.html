FINAL SCORECARD AND RISK REGISTER¶

Goal: Consolidate all findings into one clear verdict. What passed? What failed? What must happen before this model can be deployed?

Before the numbers, a reminder of what this audit set out to prove.

This audit began with one question: when the AI learns how to spot fraud, whose fraud is it actually learning from?

The Pre-Training Proxy Detection section and the Exploratory Data Analysis (E.D.A) section established that 87% of all fraud in the training data comes from High-Balance accounts. Low-Balance users contribute only 41 fraud cases out of 8,213. The fairness and bias section confirmed what that predicts: TPR = 0.6667 for Low-Balance users versus 0.9972 for High-Balance. EOD = 0.3305, more than three times the regulatory threshold.

The model is technically excellent. It is also structurally unfair to the most economically vulnerable users. Both things are true. And the regulatory framework requires that both be measured and disclosed.

fairness_results = {}
for proxy in ['tx_type_group', 'balance_group']:
    sf = s_test[proxy].values
    spd = demographic_parity_difference(y_test, y_pred, sensitive_features=sf)
    eod = equalized_odds_difference(y_test, y_pred, sensitive_features=sf)
    
    groups = sorted(np.unique(sf))
    if proxy == 'balance_group':
        order  = ['Low-Balance', 'Mid-Balance', 'High-Balance']
        groups = [g for g in order if g in groups]
    
    group_stats = {}
    for g in groups:
        mask = sf == g
        yt_g = y_test.values[mask]
        yp_g = y_pred[mask]
        tp = ((yt_g == 1) & (yp_g == 1)).sum()
        fn = ((yt_g == 1) & (yp_g == 0)).sum()
        fp = ((yt_g == 0) & (yp_g == 1)).sum()
        tn = ((yt_g == 0) & (yp_g == 0)).sum()
        tpr = tp / (tp + fn) if (tp + fn) > 0 else 0
        group_stats[g] = {
            'tp': tp, 'fn': fn, 'fp': fp, 'tn': tn, 'tpr': tpr,
            'pred_rate': yp_g.mean()
        }
    
    fairness_results[proxy] = {
        'spd': spd, 'eod': eod,
        'spd_pass': abs(spd) < THRESHOLDS['SPD'],
        'eod_pass': abs(eod) < THRESHOLDS['EOD'],
        'group_stats': group_stats
    }

Finding 1 — Data-level proxy imbalance MEDIUM Only 41 Low-Balance fraud cases exist in the full dataset. Partner with BoG to access broader incident reporting data
